# subdd-dev

Part of the [subdd](../../README.md) Claude Code marketplace. Generated by `node scripts/catalog.mjs`; do not edit by hand.

Install:

```bash
claude plugin marketplace add mauvies/subdd
claude plugin install subdd-dev@subdd
```

Engineering specialists: frontend, backend, UI/UX, DevOps, database, security, performance, QA, API design.

## Agents

| Agent | Model | When to use |
|---|---|---|
| `subdd-dev:api-designer` | opus | API designer for REST, GraphQL, RPC and event contracts. Produces OpenAPI/AsyncAPI specs, versioning and error models. Use before implementing new endpoints or public integrations. |
| `subdd-dev:backend-engineer` | inherit | Senior backend engineer for APIs, services, business logic, background jobs, queues, event-driven systems and integrations, in any server-side stack. Use for server-side implementation and fixes. |
| `subdd-dev:database-architect` | opus | Database specialist for schema design, data modeling, migrations, indexing, query optimization and choosing between relational, document, key-value and analytical stores (PostgreSQL first, also MongoDB, Redis, Supabase). |
| `subdd-dev:devops-engineer` | inherit | DevOps/platform engineer for CI/CD pipelines, Docker, Kubernetes, infrastructure as code (Terraform, Pulumi, CDK), cloud (AWS, GCP, Vercel, Fly, Cloudflare), environments, secrets and deployment strategies. |
| `subdd-dev:frontend-engineer` | inherit | Senior frontend engineer for web UIs - components, state, data fetching, forms, styling, accessibility and client performance. Use for implementing or fixing anything that renders in the browser. |
| `subdd-dev:performance-engineer` | inherit | Performance specialist for profiling and optimizing web vitals, bundle size, rendering, API latency, database queries, memory and throughput. Use when something is slow or before scaling. |
| `subdd-dev:qa-engineer` | inherit | QA and test automation engineer. Designs test strategies, writes end-to-end and integration tests (Playwright), exploratory test charters and bug reports. Use to assess release readiness or raise coverage on critical flows. |
| `subdd-dev:security-auditor` | opus | Application security auditor. Reviews code, configs and architecture for vulnerabilities (OWASP Top 10, auth, secrets, injection, SSRF, supply chain, cloud misconfig). Use before releases and on any change to auth, payments, uploads or infra. |
| `subdd-dev:ui-ux-designer` | opus | Product UI/UX designer. Use for user flows, information architecture, wireframes, interaction design, design-system tokens and components, UX reviews of existing screens, and turning requirements into concrete UI specs. |

## Workflows (you run them)

| Command | Arguments | What it does |
|---|---|---|
| `/subdd-dev:new-endpoint` | `<endpoint purpose, e.g. "list orders for current user with filters">` | Design and implement a new API endpoint contract-first - contract, tests, implementation, docs. |
| `/subdd-dev:security-audit` | `[path \| "diff" \| "full"]` | Run a security audit of the repo, a directory or the current diff with the security-auditor agent. |
| `/subdd-dev:ux-review` | `<route, component path or flow description>` | UX and accessibility review of a page, flow or component, with prioritized recommendations. |

|---|---|
