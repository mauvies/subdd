# subdd-product

Part of the [subdd](../../README.md) Claude Code marketplace. Generated by `node scripts/catalog.mjs`; do not edit by hand.

Install:

```bash
claude plugin marketplace add mauvies/subdd
claude plugin install subdd-product@subdd
```

Product and business: PM, UX research, market research, copywriting, SEO, data analysis, growth.

## Agents

| Agent | Model | When to use |
|---|---|---|
| `subdd-product:copywriter` | inherit | Conversion copywriter and content writer. Use for landing pages, product and UI microcopy, onboarding emails, announcements, social posts and blog articles in a given brand voice and language. |
| `subdd-product:data-analyst` | sonnet | Data analyst. Use for SQL queries, metric definitions, funnel and cohort analysis, A/B test analysis, dashboards and turning raw CSV/DB data into charts and conclusions. Computes in code, never estimates. |
| `subdd-product:growth-marketer` | sonnet | Growth and go-to-market marketer. Use for launch plans, acquisition channel strategy, activation and retention loops, experiment backlogs, pricing pages, and distribution for indie and B2B products. |
| `subdd-product:market-researcher` | sonnet | Market and competitive researcher. Use for market sizing (TAM/SAM/SOM), competitor analysis, pricing benchmarks, positioning, trend research and go-to-market inputs. Searches the web and cites sources. |
| `subdd-product:product-manager` | opus | Product manager. Use to clarify a product problem, write PRDs and user stories, prioritize a backlog (RICE, MoSCoW), define success metrics, or turn feedback into a roadmap. |
| `subdd-product:seo-specialist` | sonnet | SEO specialist for technical SEO audits, keyword research, content briefs, metadata, structured data, internal linking and Core Web Vitals. Use for sites, landing pages, blogs and programmatic SEO. |
| `subdd-product:ux-researcher` | sonnet | UX researcher. Use to plan user interviews and usability tests, write discussion guides and surveys, synthesize feedback or reviews into insights, and build personas and journey maps grounded in evidence. |

## Workflows (you run them)

| Command | Arguments | What it does |
|---|---|---|
| `/subdd-product:launch-plan` | `<product or feature, audience, launch date if known>` | Build a go-to-market and launch plan with copy, channels and metrics for a product or feature. |
| `/subdd-product:market-research` | `<market, niche, product category or competitor list>` | Research a market, niche or set of competitors and produce a cited report with implications. |
| `/subdd-product:prd` | `<product or feature idea>` | Write a PRD for a product idea or feature with the product-manager agent. |
