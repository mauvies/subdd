# Competitive analysis

1. **Landscape:** direct competitors, indirect alternatives, status quo (spreadsheets, agencies, doing nothing).
2. **Matrix** (one row per competitor): target customer, core value prop, key features, pricing model and entry price, distribution channel, strengths, weaknesses, recent moves. Cite the source for each cell that is a fact.
3. **Positioning map:** pick the two axes customers actually decide on; place everyone; find empty, valuable space.
4. **Pricing:** model (seat, usage, flat, freemium), tiers, anchor price, what is gated.
5. **SWOT** for our product against the field.
6. **Implications:** 3-5 bullets on differentiation, messaging and what not to compete on.
