# Copywriting frameworks

- **PAS:** Problem → Agitate → Solution.
- **AIDA:** Attention → Interest → Desire → Action.
- **BAB:** Before → After → Bridge.

## Landing page anatomy

1. Hero: outcome headline, one-line subhead with how, primary CTA, visual of the product.
2. Social proof (only real).
3. Problem framing.
4. How it works in 3 steps.
5. Benefits tied to features.
6. Objection handling / FAQ.
7. Pricing or next step.
8. Final CTA.

## Emails

Subject < 50 chars, one idea, one CTA, plain-text feel. Onboarding sequence: welcome + first action, value reminder, feature unlock, social proof, check-in.

## Microcopy

Buttons say what happens ("Create invoice", not "Submit"). Errors say what went wrong and how to fix it. Empty states explain the value and the first action.
