# SEO audit

## Technical
robots.txt, XML sitemap, canonical tags, indexability (noindex leaks), HTTP status and redirect chains, HTTPS, hreflang, rendering of content without JS, Core Web Vitals (LCP, INP, CLS), mobile usability, URL structure, pagination, duplicate content, 404s and broken links.

## On-page
Title and meta description per page, h1 and heading hierarchy, intent match, content depth vs ranking pages, internal links, image alt and sizes, structured data validity, Open Graph and Twitter cards.

## Off-page and local (if relevant)
Backlink profile overview, Google Business Profile, NAP consistency.

## Report
Table: issue, pages affected, impact (H/M/L), effort (S/M/L), fix. Sort by impact/effort. Include quick wins first.
