# subdd-typescript

Part of the [subdd](../../README.md) Claude Code marketplace. Generated by `node scripts/catalog.mjs`; do not edit by hand.

Install:

```bash
claude plugin marketplace add mauvies/subdd
claude plugin install subdd-typescript@subdd
```

TypeScript stack pack: strict typing and style, React/Next.js, Vitest/Playwright, Node backend. Loaded by the subdd agents when installed.

## Skills (Claude loads them when relevant)

| Skill | When it applies |
|---|---|
| `node-backend` | Node.js and TypeScript backend conventions - env validation, request validation, frameworks, ORMs and migrations, background jobs. Use when writing server-side TypeScript (APIs, Server Actions, workers, scripts). |
| `react-conventions` | React and Next.js conventions - component structure, hooks order, state, data fetching, forms, styling and performance. Use when creating or reviewing React components, pages, hooks or Next.js routes. |
| `typescript-style` | TypeScript typing rules and code style conventions that formatters do not enforce. Use when writing, refactoring or reviewing any TypeScript or TSX code. |
| `typescript-testing` | Testing stack and conventions for TypeScript projects - Vitest/Jest, Testing Library, Playwright, MSW, integration tests with real databases. Use when writing or running tests in a TypeScript or JavaScript project. |
